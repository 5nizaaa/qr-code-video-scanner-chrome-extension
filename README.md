# «QR на видео» — расширение для Chrome

Аналог функции Яндекс Браузера: расширение постоянно проверяет кадры видео на открытых страницах,
распознаёт в них QR-коды и сразу показывает содержимое — с кнопками «Открыть» и «Копировать».

## Возможности

- **Автопоиск QR-кодов в видео** на любом сайте: YouTube, VK, любые HTML5-плееры.
  Работает и во встроенных плеерах (iframe) и в shadow DOM.
- **Плашка поверх страницы** с содержимым кода и кнопками «Открыть» / «Копировать».
- **Системное уведомление**, если вкладка в фоне (с кнопкой «Открыть ссылку»).
- **История находок** в попапе с кнопкой открытия и копирования.
- **Переключатель вкл/выкл** сканирования.
- **Счётчик найденного** на иконке расширения.
- Работает даже с видео на паузе (реже, чем с играющим) — поставьте паузу прямо на кадре с QR.
- Если кадр видео недоступен напрямую (кросс-доменное видео), расширение делает
  скриншот вкладки и ищет код на нём (фолбэк).
- Всё выполняется **локально** в браузере: кадры никуда не отправляются.

## Установка

1. Откройте `chrome://extensions`
2. Включите переключатель **«Режим разработчика»** (справа вверху)
3. Нажмите **«Загрузить распакованное расширение»**
4. Выберите папку `qr-video-scanner`
5. Закрепите иконку в панели (значок-пазл → булавка)

Готово. Откройте видео с QR-кодом — в правом нижнем углу появится плашка с распознанным текстом.

## Попап

- Переключатель включает/выключает сканирование (действует сразу, без перезагрузки страниц).
- Список последних найденных QR-кодов: текст, источник и время.
- Кнопки «Открыть» (для ссылок) и «Копировать».

## Ограничения

- **DRM-сервисы** (Netflix, Кинопоиск и т.п.): кадры защищены от копирования,
  распознать код в них технически невозможно — Chrome сам не даёт доступ к таким кадрам.
- Сканирование идёт, только когда вкладка активна и видима (экономия CPU и батареи).
- Страницы `chrome://` и магазин расширений Chrome закрыты для расширений — это ограничение браузера.
- Локальные файлы (`file://`): разрешите доступ на странице `chrome://extensions`
  в карточке расширения («Разрешить доступ к URL файлов»).
- QR-код должен занимать заметную часть кадра (примерно от 1/6 ширины) — слишком мелкие
  коды не распознаются. Это ограничение любого распознавателя.

## Приватность

Расширение не имеет аналитики и не отправляет данные: кадры видео и результаты
распознавания обрабатываются только в вашем браузере. История хранится локально
и удаляется кнопкой «Очистить историю».

## Приятный бонус

Расширение собрано на Manifest V3, поэтому его же можно загрузить и в
**Яндекс Браузер** и в **Microsoft Edge**: там тоже есть «Загрузить распакованное
расширение» на странице `browser://extensions` / `edge://extensions`.

## Структура проекта

```
qr-video-scanner/
├── manifest.json        # манифест расширения (MV3)
├── background.js        # фоновый сервис-воркер: уведомления, история, скриншот-фолбэк
├── content.js           # сканирование <video> на страницах, плашка
├── popup.html/.css/.js  # попап: переключатель и история
├── vendor/jsQR.js       # библиотека распознавания QR (jsQR, MIT)
├── icons/               # иконки 16/48/128
└── build/gen_icons.ps1  # скрипт генерации иконок (PowerShell + System.Drawing)
```
